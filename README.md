GTA-CarpetCity
==============

Grand Theft HotWheels: Carpet City — Final Project for Computer Graphics w/ John Quinn

A browser-based 3D driving game built with Three.js. Drive a Porsche 944 across a carpet city, collect money crates, and evade police cars across escalating stages.

**[Play it live](https://tseale.github.io/GTA-CarpetCity/)**

## Controls

- **W** — Drive forward
- **S** — Reverse
- **A** — Turn left
- **D** — Turn right
- **R** — Restart (after game over)
